# qr-generator
Simple QR-code generator that supports bulk-csv, styling & logo's while fully running in your browser.

## Getting Started
To run it locally, download the [latest release](https://github.com/Joery/qr-generator/releases/latest) and open `index.html` in your browser. You can also try it online via [GitHub Pages](https://joery.github.io/qr-generator/).

## Contributing
Contributions are welcome. If you find any issues or have improvements, you can create an [issue](https://github.com/Joery/qr-generator/issues) or [pull request](https://github.com/Joery/qr-generator/pulls).
